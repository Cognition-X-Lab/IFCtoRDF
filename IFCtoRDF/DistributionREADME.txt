IFCtoRDF — READ BEFORE EXTRACTING

If you downloaded this ZIP from GitHub on Windows, Windows may mark it as an internet download. That can prevent the bundled Xbim geometry library from loading.

Before extracting:
1. In File Explorer, locate IFCtoRDF_app.zip.
2. Right-click the ZIP and choose Properties.
3. On the General tab, select Unblock (if shown), then select Apply and OK.
4. Extract the ZIP, then run IFCtoRDF.exe from the extracted folder. Keep IFCtoRDF_lib beside the EXE.

You can open this README from the ZIP listing before choosing Extract All. If you already extracted the ZIP, unblock the original ZIP, remove the old extracted copy, and extract it again.

Windows may still show a SmartScreen warning because this app is not currently code-signed. Unblocking the ZIP does not sign the app or establish its reputation. Only proceed if you verified that this is the expected release from your organization; follow your organization's security process if the warning remains.
